# Brand assets

Drop the **official** company logos here and the one-pager will use them
automatically. If a file is missing, the one-pager falls back to a clean
typographic wordmark (company name + tagline) — which is preferable to a
placeholder logo on a client-facing document.

Expected files:

| File              | Used for                        |
|-------------------|---------------------------------|
| `msb-logo.png`    | Midwest Service Bureau one-pager |
| `vegas-logo.png`  | Vegas Valley one-pager           |

Guidelines:
- PNG, transparent background
- Roughly 3.5:1 wide (rendered at ~190 x 52 pt)
- At least 600 px wide so it stays sharp in print/PDF

NOTE: the previous files here were auto-generated placeholders (a purple
box reading "M$B"), not real brand assets. They were removed because they
appeared on documents sent to clients.
